## 📙 Средний уровень (папка `middle`)

Средний уровень предполагает, что студенты уже освоили базовый синтаксис и готовы решать практические задачи на платформах для программистов.

### Описание работ:

В папке `middle` содержатся задания, которые студенты выполняют самостоятельно на специализированных онлайн-платформах. Основные ресурсы:

- **Codewars** — решение задач различной сложности (ката)
- **LeetCode** — решение алгоритмических задач

**Формат работы:**
- Студент регистрируется на выбранной платформе
- Решает задачи согласно списку, предоставленному преподавателем
- Загружает ссылки на решения или скриншоты выполненных заданий
- Список задач может варьироваться в зависимости от доступности платформы

> 📌 *Подробное описание заданий находится в файлах внутри папки `middle`.*

---

## 📕 Сложный уровень (папка `hard`)

Сложный уровень направлен на создание полноценного веб-приложения. Студентам предстоит разработать базовый мессенджер с использованием одного из популярных веб-фреймворков Python.

### Требования к проекту:

**Стек технологий (на выбор):**
- Django
- Flask
- FastAPI

**Функционал базового мессенджера:**
- Регистрация и аутентификация пользователей
- Создание чатов/комнат
- Отправка и получение сообщений в реальном времени (WebSockets)
- Хранение истории сообщений
- Базовый интерфейс (HTML/CSS/JavaScript)

**Дополнительные требования:**
- Код должен быть задокументирован
- Проект должен запускаться без ошибок
- Использование системы контроля версий (Git)

> 📌 *Детальное техническое задание находится в папке `hard`.*

## 🚀 Как начать работу

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
```

2. Перейдите в нужную папку с лабораторной работой:
```bash
cd basic/    # для базового уровня
cd middle/   # для среднего уровня
cd hard/     # для сложного уровня
```
3. Следуйте инструкциям в файлах лабораторных работ

📋 Критерии оценки
| Уровень | Критерии |
|---|----------|
| Basic |	Правильность выполнения заданий, знание синтаксиса, чистый код |
| Middle |	Количество решенных задач, эффективность алгоритмов |
| Hard |	Работоспособность приложения, качество кода, использование современных технологий|
