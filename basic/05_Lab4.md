## 1. Теоретические сведения
В программировании часто встречаются задачи, в которых требуется:

- перебрать последовательность чисел;
- выполнить арифметические вычисления;
- проверить условия делимости, простоты, симметричности и др.;
- хранить значения в списках и массивах;
- использовать вложенные циклы и математические формулы.

В Python для таких задач используются:

- `for` и `while`;
- условные операторы `if` / `elif` / `else`;
- списки и кортежи;
- функции `range()`, `sum()`, `len()`, `max()`, `min()`;
- модуль `math`.

Основными навыками являются:

1. разбиение задачи на этапы;
2. выбор подходящего цикла;
3. корректная работа с числовыми последовательностями;
4. проверка результатов вычислений.

## 2. Основные конструкции Python для вычислений

### 2.1. Цикл `for`
```python
for i in range(1, 11):
    print(i)
```

### 2.2. Цикл `while`
```python
i = 1
while i <= 10:
    print(i)
    i += 1
```

### 2.3. Список как массив
```python
arr = [1, 2, 3, 4, 5]
print(arr[0])
print(sum(arr))
```

### 2.4. Математические операции
```python
import math

print(math.sqrt(16))
print(math.isqrt(25))
```

## 8. Пример базового решения

```python
def sum_multiples(limit):
    total = 0
    for i in range(1, limit):
        if i % 3 == 0 or i % 5 == 0:
            total += i
    return total

print(sum_multiples(1000))
```

Этот пример показывает типичный способ решения задач данного типа: перебор чисел, проверка условий и накопление результата.
