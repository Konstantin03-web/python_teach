## 1. Теоретические сведения
Строка в Python — это последовательность символов. В отличие от некоторых языков программирования, строка в Python является объектом, поддерживающим множество встроенных методов.

### 1.1. Основные операции со строками

```python
s = "Python"
print(len(s))        # длина строки
print(s[0])          # первый символ
print(s[1:4])        # срез строки
print(s.upper())     # верхний регистр
print(s.lower())     # нижний регистр
print(s.count("o")) # число вхождений символа
print(s.find("th")) # поиск подстроки
```

### 1.2. Ввод строки
```python
text = input("Введите строку: ")
print(text)
```

### 1.3. Сравнение строк
```python
s1 = "abc"
s2 = "abc"
print(s1 == s2)
```

### 1.4. Сцепление строк
```python
s1 = "Hello"
s2 = "world"
print(s1 + " " + s2)
```

### 1.5. Разделение строки на список слов
```python
text = "Python is easy"
words = text.split()
print(words)
```

### 1.6. Работа со списком строк
```python
names = ["Анна", "Петр", "Мария"]
for name in names:
    print(name)
```

## 2. Основные методы строк в Python

- `len(s)` — длина строки;
- `s.upper()` — перевод в верхний регистр;
- `s.lower()` — перевод в нижний регистр;
- `s.strip()` — удаление пробелов по краям;
- `s.count(x)` — количество вхождений символа или подстроки;
- `s.find(x)` — поиск подстроки;
- `s.startswith(x)` — проверка начала строки;
- `s.endswith(x)` — проверка окончания строки;
- `s.replace(old, new)` — замена символов или подстрок;
- `s.split()` — разбиение строки на слова.

## 3. Примеры решения задач

### Пример 1. Подсчитать количество символов в строке
```python
def count_symbols(s):
    return len(s)

print(count_symbols("Python"))
```

### Пример 2. Определить, начинается ли слово с буквы "Н"
```python
def starts_with_h(word):
    return word.startswith("Н") or word.startswith("н")

print(starts_with_h("Небо"))
```

### Пример 3. Подсчитать количество букв "а" в слове
```python
def count_a(word):
    return word.lower().count("а")

print(count_a("мама"))
```

### Пример 4. Показать строку в обратном порядке
```python
def reverse_string(s):
    return s[::-1]

print(reverse_string("абвгд"))
```

## 9. Пример базового решения

```python
def count_letters(word, letter):
    return word.lower().count(letter.lower())

print(count_letters("мама", "а"))
```

Этот пример показывает, как в Python удобно реализовывать базовые задачи обработки строк.
