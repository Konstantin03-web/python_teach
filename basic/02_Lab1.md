## 1. Основные конструкции структурного программирования
Программа может быть построена из трёх базовых структур:

1. Линейная структура — операторы выполняются последовательно.
2. Разветвляющаяся структура — выполняется один из блоков в зависимости от условия.
3. Циклическая структура — один и тот же блок выполняется многократно.

Эти конструкции являются основой любого алгоритма.

---

## 2. Блоки кода в Python
В Python блоки кода выделяются отступами. Обычно используется 4 пробела. Фигурные скобки для обозначения блока не применяются.

Пример:

```python
n = 0
n += 1
summa = summa + n
```

## 3. Условный оператор if
Условный оператор в Python имеет две формы: сокращённую и полную.

### 3.1. Сокращённая форма

```python
if условие:
    оператор
```

### 3.2. Полная форма

```python
if условие:
    оператор1
else:
    оператор2
```

### Примеры

```python
# Пример 1
if a < 0:
    b = 1

# Пример 2
if a < b and (a > d or a == 0):
    b += 1
else:
    b *= a
    a = 0

# Пример 3: вложенные условия
if a < b:
    if a < c:
        m = a
    else:
        m = c
else:
    if b < c:
        m = b
    else:
        m = c
```

Для проверки нескольких условий используются логические операторы:

- `and` — логическое И;
- `or` — логическое ИЛИ;
- `not` — логическое НЕ.

## 4. Конструкция if-elif-else
Для множественного выбора используется конструкция `if-elif-else`.

```python
if условие1:
    ...
elif условие2:
    ...
elif условие3:
    ...
else:
    ...
```

Такой способ удобен, когда нужно проверить несколько взаимоисключающих вариантов.

## 5. Оператор match-case
Начиная с Python 3.10 появилась конструкция `match-case`, которая является аналогом оператора `switch` в других языках программирования.

Общая форма:

```python
match выражение:
    case значение1:
        операторы
    case значение2:
        операторы
    case _:
        операторы
```

Пример:

```python
i = int(input("Введите число: "))

match i:
    case 1:
        print("Число равно одному")
    case 2:
        print(f"2 * 2 = {i * i}")
    case 3:
        print(f"3 * 3 = {i * i}")
    case 4:
        print(f"{i} — очень красивое число!")
    case _:
        print("Завершение работы")
```

Важно: в Python, в отличие от C++, не требуется использовать оператор `break`. После выполнения выбранного блока выполнение `match` завершается автоматически.

## 6. Практическая часть

### Варианты заданий

1. Биквадратное уравнение  
   Даны действительные числа `a`, `b`, `c`, где `a != 0`. Необходимо полностью исследовать уравнение:  
   $ax^4 + bx^2 + c = 0$.  
   Если корней нет, вывести соответствующее сообщение. В противном случае вывести 2 или 4 корня.

2. Проверка чётности двух чисел  
   Даны два числа `X` и `Y`. Проверить, что оба числа чётные.

3. Замена чисел  
   Даны числа `x` и `y`. Меньшее число заменить на их полусумму, большее — на удвоенное произведение.

4. Вывод чисел  
   Даны два числа. Вывести первое число, если оно больше второго, и оба числа — если нет.

5. Кирпич и отверстие  
   Даны размеры кирпича `a`, `b`, `c` и размеры прямоугольного отверстия `x`, `y`. Определить, пройдёт ли кирпич через отверстие, если рёбра кирпича параллельны сторонам отверстия.

6. Время года  
   По номеру месяца вывести название времени года.

7. Количество дней в месяце  
   По номеру месяца и году определить количество дней в месяце.

8. Только одно нечётное число  
   Проверить истинность утверждения: только одно из двух чисел нечётное.

9. Калькулятор  
   Пользователь вводит два числа и выбирает действие: сложение, умножение, вычитание или деление. Необходимо вывести результат.

10. Стратегия ставок  
   Начальная ставка равна 10. При проигрыше ставка удваивается. В кармане 1000. Определить максимальное количество ставок, пока сумма ставок меньше 1000.

11. Проверка положительности  
   Даны три числа. Проверить, все ли они положительные. Если нет, вывести исходные числа и сообщение о том, что они не подходят.

12. Возрастная категория  
   По возрасту определить категорию: младенец, дошкольник, школьник, подросток, молодой человек, зрелый человек, пожилой человек, старый человек.

13. Горка  
   По координатам начала и конца отрезка определить: подъём, спуск, ровная дорога или пологий спуск.

14. Игральные карты  
   Даны `N` (6–14) — достоинство карты и `M` (1–4) — масть. Необходимо вывести название карты.  
   Значения: 6–10, 11 — валет, 12 — дама, 13 — король, 14 — туз.  
   Масти: 1 — бубны, 2 — трефы, 3 — червы, 4 — пики.

15. Восточный календарь  
   По номеру года определить название года по 60-летнему циклу, начиная с 1984 года (год зелёной крысы).

16. Число словами  
   Дано трёхзначное число. Необходимо вывести его словесное описание. Например: `345` → `Триста сорок пять`.
