## 1. Установка Python и VS Code
Для работы необходимы:

- Python 3.x (рекомендуется версия 3.10+ или 3.11+);
- VS Code.

После установки Python проверяется командой:

```bash
python3 --version
```

Если команда выполняется успешно, интерпретатор установлен правильно.

если что в системе может быть установлено несколько версий интерпретатора
```bash
>>python3(нажать tab)
python3            python3-config     python3.14         python3.14-config
```

## 2. Установка расширений в VS Code
В VS Code нужно установить расширения:

- Python;
- Pylance;
- Black Formatter (или autopep8, если используется другой форматтер).

Расширение Python обеспечивает:

- подсветку синтаксиса;
- проверку ошибок;
- работу с виртуальным окружением;
- запуск и отладку кода.

## 3. Создание проекта
Создаётся папка проекта, например:

```text
my_project/
```

Далее в VS Code открывается эта папка через меню: File → Open Folder.

Внутри проекта создаётся файл `main.py`.

---

## 4. Виртуальное окружение
В Python для каждого проекта рекомендуется создавать отдельное виртуальное окружение.

Создание:

```bash
python -m venv .venv
```

Активация:

- Windows:

```bash
.venv\Scripts\activate
```

- Linux/macOS:

```bash
source .venv/bin/activate
```

После активации команда `python` будет ссылаться на интерпретатор данного проекта.

---

## 5. Установка пакетов Python
Пакеты устанавливаются через менеджер `pip`.

Пример:

```bash
pip install requests
```

Для установки нескольких пакетов:

```bash
pip install numpy pandas matplotlib
```

Проверка установленных пакетов:

```bash
pip list
```

Сохранение зависимостей проекта:

```bash
pip freeze > requirements.txt
```

Установка зависимостей из файла:

```bash
pip install -r requirements.txt
```

Важно: все пакеты устанавливаются в активированное виртуальное окружение.

## 6. Форматирование кода
Форматирование делает код единообразным, читабельным и соответствующим стандартам Python.

Наиболее распространённый инструмент — `black`.

### 6.1. Установка Black
```bash
pip install black
```

### 6.2. Установка расширения в VS Code
В VS Code необходимо установить расширение:

- `Black Formatter`

### 6.3. Стандартная настройка автозапуска при сохранении
Для автоматического форматирования при сохранении файла в VS Code нужно открыть настройки пользователя (`settings.json`) и добавить:

```json
{
  "editor.formatOnSave": true,
  "[python]": {
    "editor.defaultFormatter": "ms-python.black-formatter",
    "editor.formatOnSave": true
  }
}
```

### 6.4. Дополнительные стандартные настройки Black
Для Python-проектов обычно используется стандартный стиль Black без дополнительных параметров. Это означает, что форматирование выполняется по правилам, принятым в сообществе Python.

Основные характеристики Black:

- длина строки: 88 символов;
- использование одинарных или двойных кавычек определяется стандартом Black;
- автоматическое выравнивание списков и аргументов;
- единый стиль оформления кода.

Пример:

```python
print("Hello, world!")
```

Форматтер Black преобразует код в стандартный вид, не требуя ручной правки.

### 6.5. Запуск форматирования вручную
Через терминал:

```bash
black main.py
```

Или через команду в VS Code: "Format Document".

Форматирование является обязательным элементом профессиональной разработки, так как позволяет:

- стандартизировать код;
- уменьшить число стилистических ошибок;
- повысить читаемость программы;
- упростить совместную работу в команде.

## 7. Запуск программы
После создания файла `main.py` можно выполнить:

```python
print("Hello, world!")
```

Запуск:

```bash
python main.py
```

В результате программа выводит текст в консоль.

## 8. Отладка в VS Code
VS Code позволяет использовать отладку (debug) для пошагового выполнения программы.

Основные возможности:

- точки останова (breakpoints);
- просмотр значений переменных;
- пошаговое выполнение кода;
- поиск места ошибки.

Для запуска отладки используется клавиша `F5` или меню Run and Debug.

---

## 9. Основные правила работы
1. Для каждого проекта создаётся отдельное виртуальное окружение.
2. Пакеты устанавливаются только в активированное окружение.
3. Код должен быть оформлен в едином стиле.
4. Перед запуском программы проверяется, что выбран правильный Python-интерпретатор.
5. При ошибках используется отладка, а не хаотичная правка кода.
