## 1. Теоретические сведения
Файл представляет собой последовательность данных, хранящихся на внешнем носителе. В Python работа с файлами реализована через объект файла, который создаётся функцией `open()`.

### 1.1. Открытие файла
```python
f = open("example.txt", "r", encoding="utf-8")
```

Параметры функции `open()`:

- `"r"` — чтение;
- `"w"` — запись, при этом существующее содержимое файла удаляется;
- `"a"` — дозапись в конец файла;
- `"r+"` — чтение и запись;
- `"b"` — бинарный режим.

### 1.2. Чтение данных из файла
```python
with open("example.txt", "r", encoding="utf-8") as f:
    text = f.read()
    print(text)
```

Можно читать файл построчно:

```python
with open("example.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())
```

### 1.3. Запись данных в файл
```python
with open("result.txt", "w", encoding="utf-8") as f:
    f.write("Hello, world!\n")
```

### 1.4. Дозапись в файл
```python
with open("result.txt", "a", encoding="utf-8") as f:
    f.write("Новая строка\n")
```

### 1.5. Проверка существования файла
```python
from pathlib import Path

p = Path("example.txt")
if p.exists():
    print("Файл существует")
else:
    print("Файл не найден")
```

### 1.6. Обработка ошибок
При работе с файлами необходимо учитывать возможность ошибок, например, отсутствие файла или неверный путь.

```python
try:
    with open("example.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("Ошибка: файл не найден")
```

### 1.7. Поиск подстроки в файле
Для поиска строки внутри текста удобно использовать оператор `in` или метод `find()`.

```python
pattern = "Python"
with open("example.txt", "r", encoding="utf-8") as f:
    for line in f:
        if pattern in line:
            print("Подстрока найдена:", line)
            break
```

## 2. Примеры решения задач

### Пример 1. Вывести содержимое файла
```python
with open("text.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line, end="")
```

### Пример 2. Проверить, есть ли заданная строка в файле
```python
word = input("Введите строку для поиска: ")
found = False

with open("text.txt", "r", encoding="utf-8") as f:
    for line in f:
        if word in line:
            found = True
            break

if found:
    print("Строка присутствует в файле")
else:
    print("Строка отсутствует")
```

### Пример 3. Подсчёт количества строк, содержащих заданное слово
```python
word = input("Введите слово: ")
count = 0

with open("text.txt", "r", encoding="utf-8") as f:
    for line in f:
        if word in line:
            count += 1

print("Количество строк:", count)
```

### Пример 4. Копирование файла
```python
with open("input.txt", "r", encoding="utf-8") as source:
    data = source.read()

with open("copy.txt", "w", encoding="utf-8") as target:
    target.write(data)

print("Копирование завершено")
```

## 8. Пример базового решения

```python
pattern = input("Введите строку для поиска: ")
found = False

try:
    with open("text.txt", "r", encoding="utf-8") as f:
        for line in f:
            if pattern in line:
                found = True
                print("Строка найдена:", line)
                break
    if not found:
        print("Строка отсутствует")
except FileNotFoundError:
    print("Ошибка: файл не найден")
```

Данный пример демонстрирует типичный алгоритм поиска информации в текстовом файле: чтение данных по строкам, сравнение с образцом и обработка возможной ошибки открытия файла.
