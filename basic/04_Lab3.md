## 1. Теоретические сведения
В структурном программировании массив является одной из основных структур данных. Он используется для хранения множества однотипных значений.

В языках программирования массивы могут быть:

- одномерными;
- двумерными (матрицы);
- многомерными.

### 1.1. Массивы в Python
В Python список является динамической коллекцией, то есть может изменяться по ходу выполнения программы:

- добавлять элементы;
- удалять элементы;
- менять элементы по индексу;
- иметь разную длину в процессе работы.

Поэтому в Python операции над массивами часто реализуются через списки и вложенные списки.

---

## 2. Коллекции в Python
Python имеет несколько типов коллекций, которые используются в зависимости от задачи.

### 2.1. Список (`list`)
Список — это упорядоченная изменяемая последовательность элементов.

```python
numbers = [5, 7, 2, 9]
numbers.append(10)
print(numbers)
```

Списки широко используются для хранения массивов и матриц.

### 2.2. Кортеж (`tuple`)
Кортеж — неизменяемая последовательность.

```python
point = (3, 4)
print(point[0])
```

Кортежи применяются там, где важно зафиксировать набор значений.

### 2.3. Множество (`set`)
Множество хранит уникальные элементы без порядка.

```python
values = {1, 2, 3, 3, 4}
print(values)
```

### 2.4. Словарь (`dict`)
Словарь хранит данные в виде пар «ключ: значение».

```python
student = {"name": "Иван", "age": 20}
print(student["name"])
```

### 2.5. Матрица в Python
Матрица обычно представляется как список списков.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

Это аналог двумерного массива в C++.

## 3. Пример обработки массива
Пример: сформировать матрицу случайных чисел, найти минимальный элемент, который больше заданного числа, и определить его индексы.

```python
import random


def find_min_over_threshold(matrix, threshold):
    min_value = None
    min_i = min_j = -1

    for i in range(len(matrix)):
        for j in range(len(matrix[i])):
            value = matrix[i][j]
            if value > threshold and (min_value is None or value < min_value):
                min_value = value
                min_i, min_j = i, j

    return min_value, min_i, min_j


def main():
    n, m, d = 7, 8, 100
    matrix = [[random.randint(-d, d) for _ in range(m)] for _ in range(n)]

    print("Исходная матрица:")
    for row in matrix:
        print(row)

    az = int(input("Введите заданное число az: "))
    amin, imin, jmin = find_min_over_threshold(matrix, az)

    if amin is None:
        print("Подходящих элементов не найдено.")
    else:
        print(f"Минимальный элемент: {amin}")
        print(f"Индексы: i = {imin}, j = {jmin}")


main()
```

## 4. Основные операции над массивами
Для массивов и матриц в Python часто используются:

- проход по элементам циклом `for`;
- вложенные циклы для матриц;
- сортировка списков;
- анализ строк, столбцов и диагоналей;
- преобразование списка в set, tuple или dict;
- генераторы списков.

Пример генерации списка:

```python
nums = [i for i in range(10)]
print(nums)
```

Пример матрицы:

```python
matrix = [[random.randint(0, 10) for _ in range(5)] for _ in range(5)]
```

## 10. Пример базового решения

```python
import random


def build_matrix(rows, cols, low, high):
    return [[random.randint(low, high) for _ in range(cols)] for _ in range(rows)]


matrix = build_matrix(4, 4, -10, 10)
for row in matrix:
    print(row)
```

Данный пример показывает базовый способ генерации матрицы в Python и её дальнейшей обработки.
