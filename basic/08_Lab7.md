## 1. Теоретические сведения
В языке C++ структура представляет собой совокупность полей, объединенных одним именем. Например, запись о сотруднике может содержать код, фамилию, пол, возраст и оклад. В Python аналогичной конструкцией является объект класса или словарь. Для учебных задач чаще всего удобно использовать класс `dataclass`, который позволяет компактно описывать поля записи и автоматически создавать методы и сравнение.

### 1.1. Пример структуры через `dataclass`

```python
from dataclasses import dataclass

@dataclass
class Employee:
    code: int
    surname: str
    is_male: bool
    salary: float

emp = Employee(1, "Иванов", True, 45000)
print(emp)
print(emp.surname)
```

### 1.2. Пример с использованием словаря

```python
employee = {
    "code": 1,
    "surname": "Иванов",
    "is_male": True,
    "salary": 45000
}

print(employee["surname"])
print(employee.get("salary"))
```

### 1.3. Структура и список структур
При обработке набора данных удобно хранить несколько записей в списке.

```python
employees = [
    Employee(1, "Иванов", True, 45000),
    Employee(2, "Петрова", False, 52000),
    Employee(3, "Сидоров", True, 61000),
]

for emp in employees:
    print(emp.code, emp.surname, emp.salary)
```

### 1.4. Обработка данных через функции
В Python функции используются для обработки записей и списков записей. Это позволяет разделять ввод данных, фильтрацию, сортировку и вывод.

```python
def print_male(employees):
    for emp in employees:
        if emp.is_male:
            print(emp)

print_male(employees)
```

### 1.5. Сортировка списка структур

```python
sorted_employees = sorted(employees, key=lambda e: e.salary)
for emp in sorted_employees:
    print(emp.surname, emp.salary)
```

### 1.6. Ввод данных через цикл

```python
employees = []
for i in range(3):
    code = i + 1
    surname = input("Введите фамилию: ")
    sex = input("Введите пол (m/f): ")
    is_male = sex == "m"
    salary = float(input("Введите зарплату: "))
    employees.append(Employee(code, surname, is_male, salary))
```

## 2. Основные понятия

- Структура данных — это набор взаимосвязанных полей, описывающих один объект.
- В Python структура может быть представлена:
  - словарём;
  - классом;
  - dataclass.
- Для хранения множества записей используется список.
- Для обработки данных применяются функции.
- Поля могут иметь разные типы данных: строка, число, логическое значение, число с плавающей точкой.

## 3. Примеры решения задач

### Пример 1. Создать базу сотрудников
```python
from dataclasses import dataclass

@dataclass
class Employee:
    code: int
    surname: str
    is_male: bool

employees = [
    Employee(1, "Иванов", True),
    Employee(2, "Петрова", False),
    Employee(3, "Сидоров", True),
]

for e in employees:
    if e.is_male:
        print(e.code, e.surname)
```

### Пример 2. Поиск сотрудника по коду
```python
def find_employee(employees, code):
    for emp in employees:
        if emp.code == code:
            return emp
    return None

employee = find_employee(employees, 2)
print(employee)
```

### Пример 3. Подсчёт мужчин в списке
```python
def count_males(employees):
    count = 0
    for emp in employees:
        if emp.is_male:
            count += 1
    return count

print(count_males(employees))
```

## 9. Пример базового решения

```python
from dataclasses import dataclass

@dataclass
class Employee:
    code: int
    surname: str
    is_male: bool
    salary: float

employees = [
    Employee(1, "Иванов", True, 50000),
    Employee(2, "Петрова", False, 60000),
    Employee(3, "Сидоров", True, 70000),
]

# вывести мужчин
for emp in employees:
    if emp.is_male:
        print(emp)
```

Этот пример показывает типичный способ хранения и обработки записей в Python. Основная идея заключается в том, что данные о каждом объекте хранятся вместе и обрабатываются единым набором функций.
