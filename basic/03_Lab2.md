## 1. Основные сведения
Цикл используется тогда, когда одно и то же действие требуется выполнить несколько раз.

В Python существуют две основные конструкции:

1. `for` — цикл с известным количеством повторений;
2. `while` — цикл, выполняющийся до тех пор, пока условие истинно.

Основные элементы программы, реализующей циклический процесс:

- начальное значение;
- условие продолжения цикла;
- изменение параметра цикла;
- тело цикла.

---

## 2. Оператор цикла `for`
Общий вид:

```python
for переменная in последовательность:
    тело_цикла
```

Пример:

```python
for i in range(1, 6):
    print(i)
```

Оператор `for` удобно использовать, когда количество повторений известно заранее.

---

## 3. Оператор цикла `while`
Общий вид:

```python
while условие:
    тело_цикла
```

Пример:

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

Оператор `while` применяется, когда число повторений заранее неизвестно, но известно условие завершения цикла.

---

## 4. Операторы `break` и `continue`
- `break` — прекращает выполнение цикла;
- `continue` — завершает текущую итерацию и переходит к следующей.

Пример:

```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)
```

## 5. Пример решения задачи
### Пример 1. Сумма конечного ряда
Найти сумму первых 10 членов ряда:

$$
S = \sum_{i=1}^{10} \frac{1}{i^2}
$$

```python
def example1():
    n = 10
    s = 0.0
    for i in range(1, n + 1):
        s += 1 / (i ** 2)
    print(f"Сумма ряда: {s}")
```

### Пример 2. Сумма ряда с заданной точностью
Найти сумму ряда:

$$
S = \sum_{i=1}^{\infty} \frac{i}{1 + i^2}
$$

с точностью `eps`.

```python
def example2():
    eps = float(input("Введите точность: "))
    s = 0.0
    i = 1
    term = i / (1 + i ** 2)

    while abs(term) > eps:
        s += term
        i += 1
        term = i / (1 + i ** 2)

    print(f"Сумма: {s}")
    print(f"Количество членов: {i - 1}")
```
