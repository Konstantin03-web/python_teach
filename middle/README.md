# Средний уровень - Решение задач на Codewars / LeetCode

## Цель
Закрепление навыков программирования на Python через решение практических задач на специализированных платформах.

## Требования
1. Зарегистрироваться на одной из платформ:
   - [Codewars](https://www.codewars.com/)
   - [LeetCode](https://leetcode.com/)

2. Решить задачи согласно списку

3. Для каждой задачи указать:
   - Ссылку на решение
   - Уровень сложности (kyu для Codewars / Easy/Medium/Hard для LeetCode)
   - Краткое описание подхода
   - Временную и пространственную сложность (опционально)

## Формат работы

### Обязательные задачи
Студент должен решить **минимум 10 задач**

### Задачи для повышенной оценки

#### На оценку "4" (Хорошо):
- **15 задач** 
- Задачи должны включать разные темы:
  - Строки и списки
  - Словари и множества
  - Функции и рекурсия
  - Алгоритмы сортировки и поиска
  - Работа с файлами (опционально)

#### На оценку "5" (Отлично):
- **20+ задач** 
- Обязательно наличие задач уровня:
  - Codewars: 6 kyu (минимум 3 задачи)
  - LeetCode: Medium (минимум 3 задачи)
- Решения должны быть оптимизированы
- Приветствуются нестандартные подходы

## Темы для задач


### Базовые темы (8-7 kyu / Easy)
- Работа со строками (обработка, форматирование, поиск)
- Работа со списками (сортировка, фильтрация, преобразование)
- Работа со словарями и множествами
- Условные конструкции и циклы
- Математические операции
- Функции и области видимости

### Продвинутые темы (6 kyu и выше / Medium+)
- Рекурсивные алгоритмы
- Динамическое программирование
- Работа с графами и деревьями
- Регулярные выражения
- Обработка исключений
- Генераторы и итераторы
- Декораторы и замыкания
